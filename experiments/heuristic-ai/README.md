# 启发式 AI 靶场实验

本文构造的教学模型，不含真实游戏代码、关卡或参数。文章附带的作者聊天截图只用于交代问题背景，不是实验输入。

## 复现

在仓库根目录运行（Python 3.9+，仅标准库）：

```sh
python3 experiments/heuristic-ai/experiment.py
python3 experiments/heuristic-ai/figures.py
```

第一条生成 `public/demos/heuristic-ai/data.json`，第二条从数据生成四张 SVG、`summary.md` 和正文中带标记的评测表。没有随机抽样，不需要 seed；生成规则固定在代码里。JSON 保留每个状态的合法动作、分项、排名、选择、Q 值和整局回报，包括失败项，不筛选结果。概率使用 Fraction 计算，JSON 同时保存真实期望的精确分数字符串和用于显示的小数。

Demo 直接查这份生成表，没有另一套 JS 概率公式。概率为整数百分比，血量为 0～4，互斥模式 p ≤ 0.5，共 1,265 行，包含零血量边界。`hp=0` 是终止状态，展示假想命中分以说明终止条件，不能实际行动。

## 公开规则

所有模型只以**实际减少的血量**为奖励，伤害不得超过剩余血量。每种装置是同一靶场的独立练习；没有把不同练习的动作混入同一合法动作集合。没有胜利额外奖励、贴现、资源惩罚或隐藏目标。

### 随机双发练习（一步）

单个靶，合法动作是稳射（必定命中、伤害 1）或双发（每发伤害 1）。两者各耗一步；双发的两颗子弹属于同一步内的不同命中事件。p 是每发的边缘命中概率。

- 独立：00、01、10、11 的概率为 (1-p)²、(1-p)p、p(1-p)、p²。
- 同源：同一判定决定两发；00 为 1-p，11 为 p。
- 互斥：00 为 1-2p，01 和 10 各为 p，11 为 0，故 p ≤ 0.5。
- 精确奖励：逐联合结果计算 min(HP, 命中数)，再取期望。
- 原始评分为 2p；先期望再封顶为 min(HP, 2p)；机械按对象去重为至少一次命中的概率（零血时为零）。稳射对应 min(HP,1)。这些量保留在数据中；原始评分在 HP=0 时仍可非零，它是故意保留的错误算法。

### 同源标签练习（一步）

四血靶，合法动作是稳定攻击（必中，伤害 3）或组合攻击。组合攻击只有一次 `burst-once` 判定，以 0.6 概率扣 4 血，失败扣 0。两个标签“形成组合”“后续爆发”都引用该事件，没有中间伤害或第二次判定。为隔离重复记分问题，组合攻击在本步内完整结算，不另外耗下一步。原始分 2.4+2.4=4.8，精确分 2.4；稳攻为 3，排序翻转。若将其视为未来动作，必须另计行动条件与步数，不能直接套用这里的 2.4。

### 蓄力练习（有限时域，确定性）

状态为剩余血量 HP、是否已蓄力 armed、剩余步数 turns。HP=0 或 turns=0 时立即终止。

- 未蓄力：合法动作为直射、蓄力。
- 已蓄力：合法动作为直射、爆发，不能重复蓄力。
- 直射伤害 2，保留现有蓄力。
- 蓄力伤害 0，设置 armed=True。
- 爆发伤害 5，设置 armed=False。
- 每个动作消耗一步，按剩余血量封顶。结束时未用的蓄力价值为零。

参照动态规划 `Q_h(s,a)=r+V_(h-1)(s')`，`V_0=0`，目标清空时也为零。前向合法序列枚举不调用动态规划或评分器，二者共享公开的 `step`；二者一致不能单独证明转移实现正确，额外断言核对文中解析反例和边界。

评测全集：HP=1..10 × armed∈{False,True} × turns=1..4，共 80 个状态，等权计入。另将 HP=0、turns=0 纳入求解器核对，共 110 状态。集合是公开的有限状态网格，不代表自然游戏状态的出现频率。

三个评分器均使用相同合法动作集合、相同真实伤害：

- `fixed`：即时有效伤害 + 蓄力动作固定 3 分。
- `immediate`：只算即时有效伤害，移除全部未来奖励。
- `gated`：只在 turns=1 时取消蓄力 3 分，其余同 fixed。

同分选择合法动作序列中靠前者（直射优先）。最优一致数包含所有并列最优动作。单步 regret 是 `V_h(s)-Q_h(s,chosen)`，意味着第一步后由最优策略接管；整局损失是 `V_h(s)-rollout(policy)`，全程反复按该评分器选择，两者不能混用。汇总见 `summary.md`；不声称该网格之外的胜率或性能提升。
